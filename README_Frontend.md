# 🌐 Frontend – Tutor Support System (HCMUT)

## 🎯 Mục tiêu
Phát triển giao diện người dùng (UI/UX) cho hệ thống **Tutor Support System** tại Trường Đại học Bách Khoa – ĐHQG TP.HCM, hỗ trợ sinh viên và giảng viên/tutor trong việc:
- Đăng ký và quản lý chương trình Tutor/Mentor.
- Tạo, xem, hủy hoặc dời lịch hẹn học tập.
- Gửi phản hồi và đánh giá chất lượng buổi hướng dẫn.
- Giao tiếp, trao đổi thông tin giữa sinh viên và tutor thông qua buổi học trực tiếp hoặc online.

---

## ⚙️ Công nghệ sử dụng

| Thành phần | Công nghệ |
|-------------|------------|
| Framework | **ReactJS (Vite)** |
| Ngôn ngữ | **JavaScript (ES6+)** |
| Authentication | **Firebase Authentication (Google Sign-In)** |
| Quản lý trạng thái | React Hooks / Context API |
| CSS framework | Tailwind CSS |
| UI Library | ShadCN UI / Material UI |
| Routing | React Router DOM |
| Gọi API | Axios |
| Thông báo | React Toastify |
| Quản lý form | React Hook Form |
| Phiên bản kiểm soát | Git + GitHub |

---

## 📋 Nhiệm vụ của Frontend 

1. **Thiết kế và xây dựng giao diện chính**, bao gồm:
   - Trang **đăng ký Tutor/Student**.  
   - Trang **đăng nhập và xác thực bằng Google (Firebase Auth)**.  
   - Trang **quản lý lịch hẹn** (tạo, xem, hủy, dời).  
   - Trang **phản hồi – đánh giá buổi hướng dẫn**.  
   - Trang **thông tin cá nhân người dùng**.  

2. **Tạo mockup UI cơ bản bằng Figma** để định hướng thiết kế.  
3. **Phối hợp với Backend** để kết nối và hiển thị dữ liệu động.  
4. **Đảm bảo UI/UX** hiện đại, tối giản, dễ sử dụng, và tương thích trên nhiều thiết bị.
